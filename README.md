# SBAM Mobile  Verified Official Links

Web-based progressive mobile application shell for SBAM.

## Features
- Mobile Web App / PWA support via Webmanifest
- Offline Cache support via Service Worker
- Day/Night appearance modes and custom theme colors

## How to Run Locally
1. Clone the repository: `git clone <repository-url>`
2. Open `index.html` in any browser or serve using a static web server.
